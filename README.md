## Описание проекта

Исследование посвящено анализу предложений рынка труда для несовершеннолетних
на основе данных о вакансиях портала «Работа в России». Цель работы — построить
типологию предложений, выявить реальные условия трудоустройства школьников и
определить модели взаимодействия работодателей с этой аудиторией.

Применён смешанный исследовательский дизайн:
- статистический и дескриптивный анализ 2 213 вакансий
- кластеризация (агломеративная иерархическая, PCA, k=8)
- регрессионный анализ часовой ставки (Linear Regression + Random Forest)
- NLP-анализ текстовых описаний (multilingual-e5-base, KeyBERT, BERTopic)
- 8 глубинных интервью с работодателями и школьниками

## Методология

### Инструменты
- **Python 3.11**: pandas, numpy, scipy, statsmodels, scikit-learn
- **Визуализация**: matplotlib, seaborn, plotly, geoplot
- **NLP**: sentence-transformers (multilingual-e5-base), KeyBERT, BERTopic,
  pymorphy3, umap-learn, hdbscan
- **Среда**: Jupyter Notebook / Google Colab (GPU Tesla T4)

### Этапы анализа

1. **Предобработка** — удаление дубликатов, заполнение пропусков медианой,
   нормализация текстовых полей, парсинг JSON-признаков, винзоризация зарплат
   (99-й перцентиль), создание индекса `school_suitability`

2. **Дескриптивный анализ** — распределение по профессиям, регионам,
   типам занятости, уровню зарплат и требованиям к образованию

3. **Групповой анализ** — критерий Краскела–Уоллиса для проверки гипотез
   о межгрупповых различиях по зарплате (отрасль, регион, тип занятости)

4. **Кластеризация** — PCA (15 компонент, 90% дисперсии) +
   агломеративная кластеризация (linkage='ward'), k=8 определено методом
   локтя и силуэтным коэффициентом

5. **Регрессионный анализ** — прогнозирование часовой ставки:
   Linear Regression (R²=0,39) vs. Random Forest (R²=0,51);
   оценка важности признаков через permutation importance и PDP

6. **NLP-анализ** — лемматизация (pymorphy3), эмбеддинги
   (multilingual-e5-base, 768 измерений), извлечение ключевых фраз
   (KeyBERT, MMR), тематическое моделирование (BERTopic, UMAP + HDBSCAN)

## Ключевые результаты

- **93,6%** вакансий не требуют опыта работы; медианная зарплата —
  **27 100 руб.** (уровень МРОТ 2026 года)
- Реально доступны школьникам лишь **37–38%** вакансий с формальной
  пометкой «несовершеннолетние» (кластеры 0 и 1)
- **46,5%** предложений (кластер 2) фактически рассчитаны на взрослых
  работников несмотря на маркировку
- Доступность вакансии для школьника **обратно связана** с её оплатой:
  чем лучше формат для подростка, тем ниже часовая ставка
- NLP-анализ: **52%** требований — личные качества (ответственность,
  дисциплинированность); описания вакансий шаблонны и малоинформативны
- Выявлено **5 типов** взаимодействия работодателей со школьниками:
  операционный найм, сезонный найм, имиджевое вовлечение,
  HR-бренд / IT-трек, неформальный рынок
